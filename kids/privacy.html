Privacy

Money Muncher Kids is intended to be playable without collecting personal information.

Current Launch Plan

  • No account registration.
  • No public chat or user-generated public text.
  • Dino Munch guided chat is for family learning and should not be used for private details.
  • No ads or ad tracking.
  • No public leaderboard.
  • No analytics cookies.
  • Game progress is saved locally on the device using browser storage.

Before Adding Online Features

Features like accounts, global leaderboards, analytics, multiplayer, or guided AI chat should be reviewed for child privacy, parental notice, consent requirements, moderation, and data retention.
